# shogi_title_info

将棋八大タイトル戦の最新状況をスマートフォン向けにまとめた、単一ページの静的サイトです。

## 機能

### タイトル戦の一覧表示（`index.html`）

- **現保持者バー**: 現在のタイトル保持者と冠数を表示
- **進行中 / 今期終了のセクション分け**: タイトル戦ごとのカードで状況を整理
- **タイトル戦カード**:
  - 期数・番勝負の種類、状況バッジ（進行中・防衛・奪取など）
  - 防衛側と挑戦者の対戦カード
  - スコア表示（勝敗を丸印で表現）
  - 各局の日付・会場・結果、進行中の場合は次の対局を強調表示
- **更新日表示**: ヘッダーとフッターに「〇年〇月〇日時点」を表示

### AI検索

- ページ内のデータ（`SHOGI_CONTEXT`）をもとに、自然な日本語で質問できる検索ボックス
- よく使う質問のクイック検索チップ
- 回答はタイプライター風に表示し、閉じるボタンで消去
- Enterキーでも検索可能
- Claude API（Anthropic Messages API）を呼び出して回答を生成

### 画面・操作性

- モバイル向けレイアウト（最大幅430px）
- 検索バーは画面上部に固定表示
- 和風デザイン（Noto Serif JP / Noto Sans JP）

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | タイトル戦情報ページ（HTML・CSS・JavaScriptを1ファイルに内包） |

## データの更新方法

データは静的で自動更新されません。更新時は次の2か所を同時に書き換えます。

1. ページ本体のカード類・現保持者バー・日付表記
2. `index.html` 内の `SHOGI_CONTEXT`（AI検索が参照するデータ）
